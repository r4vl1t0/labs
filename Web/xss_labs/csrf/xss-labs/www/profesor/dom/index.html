👋 Página de bienvenida

Objetivo de la demo: mostrar que la vulnerabilidad puede existir 100% en el navegador, sin que el servidor procese el dato inyectado (no hay ningún request al backend con el payload).

Bienvenido,

▶ Cómo funciona (código fuente)

const params = new URLSearchParams(location.search);
const nombre = params.get('nombre') || 'invitado';
// VULNERABLE: se usa innerHTML con datos no confiables
document.getElementById('saludo').innerHTML = nombre;

Payload de ejemplo:

?nombre=<img src=x onerror=alert('DOM XSS')>

Ejecutar demo ahora

🔧 Corrección (mostrar al final de la demo)

document.getElementById('saludo').textContent = nombre;

Usar textContent en vez de innerHTML, o sanitizar con una librería como DOMPurify si se necesita HTML.
