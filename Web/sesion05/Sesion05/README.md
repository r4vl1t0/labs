# Laboratorios de autenticacion y autorizacion

Aplicacion vulnerable para clase, con laboratorios de estudiante y profesor.

## Levantar

```bash
docker compose up --build
```

Abrir:

```text
http://localhost:3000
```

## Credenciales

Profesor:

```text
test:qwerty
```

Estudiante:

```text
user:987654321
```

El laboratorio final esta en una ruta no enlazada desde el indice.
